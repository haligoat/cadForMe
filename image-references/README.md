# Image references

Drop photos, sketches, screenshots or drawings here (PNG, JPG, GIF, WebP, HEIC). cadForMe shows them in the AI panel.

- Click a thumbnail, or type `@name` (the file name without its extension), to point a request at that picture:
  "model the bracket in @bracket-photo, 5 mm thick".
- Saying "the reference image" or "the picture" uses every image in the folder (up to 8).
- Write dimensions on a sketch and the AI uses them; anything the picture doesn't show, it picks and tells you.

A project can have its own `image-references/` folder; it's used instead of this one when it exists.
